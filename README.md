# Margin · 边栏笔记

在 VS Code 中用文字阅读小红书和知乎的推荐、搜索结果、正文与评论。

A text reader for Xiaohongshu and Zhihu in desktop VS Code. Uses a dedicated local Chrome/Edge session; no developer-operated backend or extension telemetry.

**实验性版本 / Preview**。这是独立的第三方项目，与小红书、知乎、Microsoft 没有官方关联。网站可能要求验证、限制访问或改变页面结构；不保证账号安全或规避检测。请遵守对应网站的使用规则，只读取账号有权访问的内容。

## 能做什么

- 小红书：发现推荐、栏目切换、搜索、文字正文与评论。
- 知乎：首页推荐、搜索、问题的回答列表、回答与文章正文。
- 一级评论和回复分别加载；显示网站提供的发布时间、编辑时间与评论时间。
- 结果列表支持文字筛选、刷新与加载更多。正文使用只读 `reading-notes.md` 标签页。
- 缓存最近读取的内容；可收起和恢复阅读，主动刷新才重新读取已缓存内容。

阅读界面不显示图片和视频，但官网浏览器仍可能下载这些资源。Chrome 启动时可能短暂出现或抢焦点；没有“不留痕迹”或“防检测”的保证。

## 安装与登录

需要桌面版 VS Code **1.96+** 和本机 **Chrome 或 Edge**。当前 macOS 已做本机测试；Windows / Linux 的安装和浏览器兼容性仍需实机验证。不支持 vscode.dev，远程工作区未验证。

本项目尚未发布市场。当前通过扩展页右上角 `…` → **从 VSIX 安装**，选择本地构建的 `margin-notes-*.vsix`。

1. 在受信任的本地窗口中，打开命令面板，运行 **Margin: 切换平台（小红书 / 知乎）**。
2. 运行 **Margin: 登录 / 处理验证**，在专用浏览器窗口中直接登录官网。
3. 登录完成后，回到 VS Code 运行 **Margin: 完成登录并关闭浏览器**。此操作保留登录态，不会退出账号。
4. 运行 **Margin: 打开（发现 · 推荐）**，选择条目阅读。

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 打开推荐 | `⌘⌥M` | `Ctrl+Alt+M` |
| 搜索当前平台 | `⌘⌥;` | `Ctrl+Alt+;` |
| 收起 | `⌘⌥.` | `Ctrl+Alt+.` |
| 恢复阅读 | `⌘⌥,` | `Ctrl+Alt+,` |

搜索命令发起新的官网搜索；列表内输入文字只筛选已载入结果。正文的行内操作需要启用 VS Code CodeLens。快捷键冲突时，可在键盘快捷方式中搜索 `Margin` 修改。

## 评论与已知限制

“加载更多评论”加载一级评论；每条评论下面的回复入口只展开该条评论。网站改版、付费限制或已关闭的浏览器上下文可能导致读取失败。

2026-10-10 的知乎单篇回答实测读到 10 条一级评论和 2 条随附回复。**后续评论分页、单独展开现代评论界面的回复，以及其他帖子类型尚未完整官网实测。** 离线测试使用合成内容，不代表所有账号和网络均能正常访问。

## 设置与故障处理

- `margin.browserPath`：可选的本机浏览器可执行文件路径；只采纳用户级配置。
- `margin.backgroundWindow`：默认开启，尝试最小化专用阅读窗口；登录窗口保持可见。
- `margin.headless`：默认关闭；无窗口模式的官网兼容性未验证。
- 提示“登录窗口仍在打开”：运行 **Margin: 完成登录并关闭浏览器**，再打开推荐。
- 提示“联网已暂停”：网站验证或访问限制触发了本地暂停。稍后主动运行 **Margin: 登录 / 处理验证** 查看官网提示，不要反复刷新。清除浏览器会话或重载不会解除暂停。
- 读取错误直接显示在阅读页；关闭通知也能看到。官网可读但插件失败时，请按 [反馈说明](SUPPORT.md) 提供脱敏信息。

## 数据和隐私

账号会话保存在本机独立浏览器目录。扩展不读取日常浏览器的 Cookie，不把正文写入项目，不添加遥测，也不使用开发者运营的中转服务。官网仍会接收访问请求，并可能记录搜索、浏览行为和浏览器信息。

卸载前，分别切换平台运行 **Margin: 清除登录和阅读会话**，删除对应的专用浏览器目录。卸载本身不保证删除这些数据，服务端设备登录状态也不会自动撤销。详情见 [隐私说明](PRIVACY.md)。
