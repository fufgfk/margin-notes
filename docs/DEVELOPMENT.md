# Margin · 边栏笔记

一个低干扰的 VS Code 小红书 / 知乎文字阅读器。推荐与搜索结果使用原生选择框，知乎问题可以进入回答列表，正文和评论显示在只读 `reading-notes.md` 标签页；阅读界面不显示图片、视频或活动栏图标。

**当前版本：0.5.3，实验性。** 使用 Patchright 驱动本机 Chrome/Edge，默认有窗口运行并尝试最小化。操作仍在 VS Code 中完成，登录或人工验证时才需要切到官网窗口。阅读标签页在后台创建，避免刷新或打开帖子时恢复最小化窗口。首次启动浏览器时仍可能短暂显示、抢焦点；最小化并不保证网站将访问视为真人。

作者信息旁显示帖子、评论及回复时间：接口时间戳转换为北京时间（年月日、时分），网页回退保留官网显示的日期或相对时间。缺失时不显示，不额外请求；编辑时间不会冒充接口发帖时间。

阅读操作串行执行；快速连续操作时，排队中已被新操作替代的任务不再访问网站，已经发出的请求可能完成。搜索、发现、正文各复用一个阅读标签页，刷新时重新导航但不重复创建标签页。

搜索结果、发现栏目、正文和已读取的评论缓存于内存（最近 15 个列表、30 篇帖子）。重复搜索、切回已读取栏目、再次打开帖子优先使用缓存；列表右上角的刷新、正文顶部的“刷新正文”才会主动重新读取。缓存不写进项目，重载 VS Code 后消失。正文打开后不再自动滚动补取评论；需要时点击末尾“加载更多一级评论”。官网自身仍可能在页面打开时加载评论和资源。

遇到官网安全验证、IP 风险、相关接口拒绝/限流或接口返回失败，当前联网会话关闭并暂停；再次搜索、收起/恢复不会自动重试。已缓存文字仍可读取，需要用户稍后主动运行“登录 / 处理验证”才能重开会话。暂停标记保存在本地扩展存储，重载 VS Code 或清除浏览器会话不会解除；只有主动打开登录 / 验证窗口成功后才解除。该标记不是服务端账号限制状态的检测或解除。

0.5.0 的知乎接入使用合成 HTML/JSON 和独立临时 profile 做离线测试，覆盖首页推荐、搜索、问题回答列表、回答 / 文章正文、评论、逐条回复和平台隔离。**知乎官网兼容性仍待专用窗口手动登录后验证**；离线通过不代表首页个性化推荐或当前官网结构已实测。小红书现有回归也使用本地页面，不访问日常账号，不保证规避风控。历史版本的官网实测仅证明当时可读取内容，不能证明账号安全。

## 安装与首次使用

1. 安装桌面版 VS Code（1.96+）与 Chrome 或 Edge。
2. 在扩展页右上角 `…` 选择 **从 VSIX 安装**，选择 `margin-notes-0.5.3.vsix`。
3. 打开受信任的本地窗口。运行 **Margin: 切换平台（小红书 / 知乎）** 选择平台，再运行 **Margin: 登录 / 处理验证**。未登录时列表可能先提示读取失败，可直接打开登录窗口。
4. 在弹出的专用浏览器中直接登录当前平台的官网。完成后关闭浏览器窗口，或运行 **Margin: 完成登录并关闭浏览器**。
5. 按 **⌘⌥M**（Windows / Linux：**Ctrl+Alt+M**）打开推荐，回车选择帖子。列表右上角可切换栏目、刷新、进入搜索；也可直接运行 **Margin: 搜索当前平台**。
6. 正文顶部有 **发现 / 切换栏目 / 搜索 / 返回列表 / 刷新正文 / 收起**。一级评论列表末尾有 **加载更多评论**，每条有剩余回复的评论下有 **展开回复 / 加载更多回复**。这些行内操作需要开启编辑器 CodeLens。

搜索框用于新搜索，结果框内输入用于筛选已经载入的结果。列表末尾可以加载更多。加载更多评论只翻页一级评论，不主动展开回复；展开回复只点击指定评论的官网展开按钮。加载状态显示在对应位置，完成后保持阅读位置。浏览器关闭后，若目标评论尚未重新载入官网页面，需要先重新加载一级评论。

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 打开推荐 | `⌘⌥M` | `Ctrl+Alt+M` |
| 搜索 | `⌘⌥;` | `Ctrl+Alt+;` |
| 收起 | `⌘⌥.` | `Ctrl+Alt+.` |
| 恢复阅读 | `⌘⌥,` | `Ctrl+Alt+,` |

可在 VS Code 键盘快捷方式中搜索 `Margin` 修改。收起会关闭 Margin 文本标签和专用浏览器，保留最近的列表、笔记及阅读位置于内存；恢复会回到收起前的列表或正文，已有缓存时不自动联网。首次恢复没有缓存时，会读取推荐。VS Code 重载后阅读缓存消失。浏览器关闭后再次加载评论/列表时，网站分页会从头恢复，已读取内容会去重合并。


## 知乎阅读

- 命令面板、列表右上角或正文顶部的“切换平台”选择知乎；默认入口是**首页推荐**，不是热榜。
- 刷新替换首页推荐，加载更多追加并保留位置。实际推荐由网站提供，不保证每次刷新不同；没有自动刷新或后台抓取。
- 列表标明问题、回答、文章。问题打开回答列表，再选择回答；回答和文章直接打开文字正文。“返回列表”回到回答列表，“返回推荐 / 搜索”回到最初列表。
- 发布时间与编辑时间分别显示。正文只展示账号当前可访问的内容；付费 / 摘要限制会提示，不绕过权限。
- 一级评论末尾分页，每条根评论分别展开回复。重复页面没有新增内容时停止该分页重试，刷新正文 / 列表后才恢复，避免反复发相同请求。
- 小红书和知乎分别保存登录 profile、网络暂停、内存缓存和阅读状态。切换关闭上一平台的浏览器，切回可恢复缓存；保留已有小红书登录目录。
- 登录和清除命令只作用于当前平台。知乎遇到访问限制会暂停自己的联网，小红书暂停状态不受影响。

## 登录与兼容性

- `margin.browserPath`：可选的 Chrome/Edge 可执行文件完整路径。macOS 例：`/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`。
- `margin.headless`：默认 `false`，使用有窗口浏览器。保留无窗口兼容选项，但不保证其可访问或避免风控。
- `margin.backgroundWindow`：默认 `true`，阅读时尝试最小化专用窗口；登录/验证时不最小化。最小化失败会提示错误，可关闭此选项使用可见窗口。
- 配置只采纳用户级设置；项目不能指定要执行的浏览器路径。
- 首次登录在可见窗口进行。阅读界面仍只显示文字，但浏览器允许官网域名的图片、视频和字体正常下载，实际流量可能比旧版增加。为维持域名访问限制，继续阻止 Service Worker。
- 看到 `300012`、安全验证、接口拒绝或限流时，联网会话停止；稍后主动使用登录命令查看官方提示，不连续重试。
- 某些页面和回复可能无法提取。网页有内容而插件为空时，请反馈**不含 Cookie、token 的错误描述**。
- 只支持本地桌面扩展宿主；不支持 vscode.dev。远程工作区的兼容性未验证。

## 数据与安全边界

- 使用独立 Chrome/Edge profile，不读取或复制日常浏览器的 Cookie；登录只在对应平台官网完成，不使用二维码代理服务。
- 不将 Cookie 写入 VS Code 设置。profile 位于扩展的 `globalStorage` 目录，macOS/Linux 顶层目录权限为 `0700`。这是浏览器自身的会话存储，**并不保证所有文件或 token 都经过加密**。
- 扩展不持久保存搜索历史，不把笔记写进项目，不添加遥测。浏览器自身仍可能记录专用会话的历史、缓存和网站存储；平台网页也可能发送其自身的统计请求。
- 浏览器请求按平台分别限制：小红书及其 CDN/短链域，或知乎 `zhihu.com` / `zhimg.com` 的 HTTPS 域名，不关闭 TLS 证书验证，不执行 shell，不开放固定调试端口。
- 外部内容只作为文字显示，不渲染 HTML、不生成可执行的命令链接。
- **Margin: 清除登录和阅读会话**会关闭专用浏览器，删除当前平台专用 profile，并清空该平台内存中的阅读内容。另一个平台的会话保留。卸载前建议运行一次；浏览器账号的服务端登录会话是否撤销由网站控制，需要时在对应平台账号设置退出设备。
- 编辑器可能记住虚拟文档标签名 `reading-notes.md`；扩展路径中不放帖子 id、搜索词或 token。收起不清除系统窗口记录、网络记录或浏览器进程审计。

读取失败或联网暂停时，阅读页会直接显示原因，并在需要时提供“登录 / 处理验证”入口；即使关闭扩展通知，也能看到提示。

## 开发与验证

```sh
npm ci --ignore-scripts
npm test
npm run check
npm run test:host
npm run package
```

`npm test` 中的真实浏览器测试需要本机 Chrome。`test:host` 默认使用 macOS `/Applications/Visual Studio Code.app/Contents/MacOS/Code`，其他系统可通过 `VSCODE_EXECUTABLE` 指定 VS Code 可执行文件。测试宿主使用仓库内 `.test-vscode` 独立目录，不改动日常 VS Code 的配置。

按 F5 启动扩展开发窗口。`src/model.ts` 处理外部数据，`capture.ts` 观察网页原生响应，`dom.ts` 提供 DOM 后备提取，`browser.ts` 管理独立会话，`extension.ts` 提供原生交互。

本地 fixture 测试验证软件逻辑；线上结果是上述日期与会话的实测，不代表所有账号、帖子或网络都能访问。

2026-10-10 评论入口修复：忽略按钮图标的零宽字符；仅展开当前回答的评论；首次展开等待评论数据，避免把加载中的空占位当成结果。专用登录会话的单篇回答实测读取到 10 条一级评论及 2 条随附回复；不代表所有页面或后续分页均已验证。

0.5.3：列表不再因后台浏览器短暂抢焦点而关闭或取消刷新；仍可按 Esc 或运行收起命令关闭。真实 VS Code 宿主覆盖了读取期间失焦、完成后直接打开结果的流程。
